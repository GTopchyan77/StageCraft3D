# Տեսարաններ պահել և բացել
keywords: պահել, պահպանել, բացել, տեսարան, ֆայլ, ավտոպահպանում, վերականգնել, ձևանմուշ, save, open, scene, autosave, recover, template

Տեսարանը ամբողջ բեմն է. իրերը, սարքերը, պատչը, կյուները, փլեյբեքները, պալիտրաները, խմբերը և էֆեկտները։ File › Save Scene As... պահում է այն անունով (Ctrl+S-ը նորից պահում է), File › Open Scene-ը բացում է, և նախ հարցնում է, եթե բեմն ունի չպահված փոփոխություններ։

File › New from Template-ը սկսում է պատրաստի բեմից։ StageCraft-ը նաև ավտոմատ պահպանում է. File › Recover Autosave-ը վերադարձնում է տեսարանի վերջին ավտոպահպանումը։ Օգնականը երբեք չի պահում, բացում կամ մաքրում բեմը ձեր փոխարեն։
