# Web Remote. վահանակի կառավարում հեռախոսից կամ պլանշետից
keywords: վեբ հեռակառավարում, հեռախոս, պլանշետ, բրաուզեր, պին, զուգակցում, հեռակառավարում, wifi, web remote, phone, tablet, browser, pin, pair, ipad, android, iphone
panel: StageCraft.Panel.Preferences

Web Remote-ը թույլ է տալիս հեռախոսից կամ պլանշետից կառավարել վահանակը բրաուզերով, առանց որևէ հավելված տեղադրելու. cue GO և BACK, cue-երի ցանկը, տասը playback-ները (մակարդակ, flash, GO, release), Grand Master-ը, Blackout-ը և Audio master-ը։ Ամեն շարժում անցնում է նույն կանոններով, ինչ վահանակի վրա սեղմումը. եթե նստաշրջանը դա չի թույլատրում, այն մերժվում է, և հեռախոսը ցույց է տալիս պատճառը։ Հեռավոր շարժումները չեն հետարկվում, ինչպես վահանակինը։

- Միացրեք այն Preferences > WEB REMOTE բաժնում։ This PC-ն սպասարկում է միայն այս համակարգչի բրաուզերը, Network-ը՝ նույն ցանցի հեռախոսներն ու պլանշետները։ Հեռախոսը և համակարգիչը պետք է լինեն նույն Wi-Fi կամ լարային ցանցում։
- Հեռախոսում բացեք Preferences-ում նշված հասցեն (օրինակ՝ http://192.168.1.20:8080) և մուտքագրեք 6 նիշանոց PIN-ը։ Օգտագործեք թվերով հասցեն. համակարգչի անունով հասցեն մերժվում է, որպեսզի այլ կայք չկարողանա հասնել հեռակառավարմանը։
- Զուգակցված հեռախոսը մնում է զուգակցված, մինչև StageCraft-ը փակվի կամ բեմը փոխվի։ Wi-Fi-ի ընդհատվելուց հետո էջն ինքն է վերամիանում։
- NEW PIN-ը փոխում է PIN-ը նոր հեռախոսների համար. արդեն զուգակցվածները մնում են։ UNPAIR ALL-ն անջատում է բոլոր հեռախոսները. յուրաքանչյուրը պետք է նորից զուգակցվի նոր PIN-ով։
- Անընդմեջ հինգ սխալ PIN մուտքագրած սարքը պետք է սպասի 30 վայրկյան, մինչև նորից փորձի։ Շատ սխալ PIN-երից հետո StageCraft-ը նաև նոր PIN է ստեղծում։
- Հեռախոսի ֆեյդերները հետևում են վահանակին, իսկ վահանակը՝ հեռախոսին։ Կարելի է զուգակցել մինչև ութ հեռախոս, և բոլորը տեսնում են նույն շոուն։
- Կապը պարզ HTTP է, գաղտնագրված չէ. օգտագործեք այն վստահելի ցանցում, ինչպես OSC-ն։ Ցանցի երթևեկը կարդալ կարողացողը կարող է տեսնել PIN-ը։
- Network-ն առաջին անգամ ընտրելիս Windows-ը կարող է հարցնել՝ թույլատրե՞լ StageCraft-ին օգտագործել ցանցը։ Թույլատրեք մասնավոր ցանցերը։
- Սկրիպտներն ու stream deck-ի նման կոճակները կարող են ուղարկել նույն հրամանները. զուգակցեք POST /api/pair-ով, ապա POST /api/command՝ թոքենով և Help: MIDI and OSC-ի ուղիով, օրինակ՝ {"path":"/stagecraft/cue/go"}։
