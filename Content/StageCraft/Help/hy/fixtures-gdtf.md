# Սարքերի ներմուծում (GDTF)
keywords: ներմուծել սարք, սարքի ֆայլ, սարքերի գրադարան, արտադրող, ռեժիմ, DMX ռեժիմ, ալիքներ, փոխարինել, հեռացնել, տեսակ, gdtf, import fixture, fixture library, dmx mode, replace, remove
panel: StageCraft.Panel.Library

GDTF ֆայլը (.gdtf) նկարագրում է իրական սարքը՝ իր DMX ռեժիմները, ալիքները, անիվները և գույները։ Արտադրողները հրապարակում են դրանք, օրինակ՝ gdtf-share.com կայքում։ StageCraft-ը յուրաքանչյուր ֆայլից ստեղծում է Library-ի սարք, որը կարող եք տեղադրել, պատչել, ծրագրավորել և DMX OUT-ով ուղարկել իրական սարքերին։

- Ներմուծում. Library-ում սեղմեք IMPORT (կամ File > Import Fixtures (GDTF)...) և ընտրեք .gdtf ֆայլը, կամ քաշեք այն Explorer-ից Library-ի կամ տեսադաշտի վրա։
- Մինչև որևէ բան ավելացնելը տեսնում եք ներմուծման հաշվետվությունը՝ արտադրողը և անունը, յուրաքանչյուր DMX ռեժիմ՝ իր ալիքների քանակով, և քանի ալիք է StageCraft-ը կառավարում, մոտավոր կառավարում կամ միայն ուղարկում իր լռելյայն արժեքով (Focus, Control և նմանատիպ)։ Այն ռեժիմները, որոնք StageCraft-ը չի կարող օգտագործել, նշված են պատճառով։ Անհրաժեշտության դեպքում ուղղեք KIND-ը, ապա սեղմեք ADD կամ CANCEL։
- Սարքը Library-ում երևում է մեկ քարտով՝ ռեժիմների քանակով։ Սեղմեք այն՝ առաջին ռեժիմով տեղադրելու համար։ Ռեժիմը փոխեք ինսպեկտորի Type դաշտում. յուրաքանչյուր ռեժիմ պահում է իրական footprint-ը, և փոփոխությունը մեկ հետարկման քայլ է։
- Արդեն եղած սարքի ֆայլը ներմուծելիս երևում է REPLACE. տեղադրված սարքերն անցնում են նույն անունով ռեժիմին և պահում են իրենց պատչն ու ծրագրավորումը։
- Քարտի REMOVE-ը (երկու սեղմում) ջնջում է սարքի տեսակը։ Այն մերժվում է, քանի դեռ այդ տեսակի սարքեր կան բեմի վրա։
- Ֆայլը պատճենվում է Library-ում, ուստի սարքը հաջորդ գործարկմանը նույնպես այնտեղ է։ Այն տեսարանը, որն օգտագործում է այս համակարգչում բացակայող սարք, ասում է, թե որ ֆայլը ներմուծել։
