# StageCraft Pro. բաժանորդագրություն և լիցենզիա
keywords: պրո, բաժանորդագրություն, լիցենզիա, ամսական, տարեկան, անցանց, թարմացում, ազատել, չեղարկել, հաշիվ, անվճար, յունիվերս, pro, subscription, licence, license, subscribe, monthly, yearly, offline, refresh, release, cancel
panel: StageCraft.Panel.Preferences

StageCraft-ը անվճար է նախագծման համար. բեմեր, ռիգինգ, լուսավորություն, cue-եր, փաստաթղթեր, GDTF և MVR ներմուծում, և DMX OUT-ի մեկ յունիվերս։ StageCraft Pro-ն ավելացնում է DMX OUT-ի անսահմանափակ յունիվերսներ, DMX IN (Art-Net և sACN մուտք), MIDI և OSC կառավարում, Web Remote և MVR արտահանում։ Pro-ն ամսական կամ տարեկան բաժանորդագրություն է։

- Բաժանորդագրվեք Preferences > STAGECRAFT PRO բաժնում։ Նախ մուտք գործեք StageCraft Cloud (Marketplace > SIGN IN)։ MONTHLY կամ YEARLY կոճակը բացում է վճարման էջը ձեր բրաուզերում. StageCraft-ը երբեք չի տեսնում ձեր քարտը։ Pro-ն ինքն է միանում, երբ վճարումը հաստատվում է։
- Pro-ն աշխատում է անցանց՝ ամեն անգամ 14 օր։ Ամեն անգամ, երբ StageCraft-ը բաց է և մուտք գործած, այն թարմացնում է այս համակարգչի լիցենզիան (գործարկման, մուտքի ժամանակ և ամեն 12 ժամը մեկ)։ REFRESH-ը թարմացնում է այն անմիջապես, օրինակ՝ առանց ինտերնետի շոուից առաջ։
- Երբ լիցենզիայի ժամկետը լրանում է, Pro հնարավորությունները կողպվում են։ Ձեր բեմերը մնում են լիովին օգտագործելի. լույսերը, պատչը և բոլոր յունիվերսները պահպանվում են, և DMX OUT-ը շարունակում է ուղարկել ամենացածր յունիվերսը։ MIDI-ն, OSC-ն և Web Remote-ը փակվում են, որպեսզի դրանց համար ոչ մի պորտ բաց չմնա։ Թարմացրեք լիցենզիան, և ամեն ինչ նորից կաշխատի ձեր կարգավորումներով։
- Անվճար DMX OUT-ը ուղարկում է պատչված ամենացածր յունիվերսը։ Patch վահանակը նշում է հետ պահված յունիվերսները։
- Մեկ բաժանորդագրությունը ծածկում է մինչև 3 համակարգիչ։ RELEASE THIS PC-ն ազատում է այս համակարգչի տեղը, օրինակ՝ այն փոխարինելուց առաջ։
- MANAGE-ը բացում է ձեր բաժանորդագրությունը բրաուզերում. չեղարկել, փոխել քարտը կամ ներբեռնել հաշիվները։ Չեղարկված բաժանորդագրությունը գործում է մինչև վճարված ժամանակաշրջանի ավարտը։
- Լիցենզիան պատկանում է այս համակարգչին և այս Windows օգտատիրոջը։ Այլ համակարգչում պատճենված՝ այն չի աշխատում. փոխարենը մուտք գործեք այնտեղ։
- Եթե StageCraft-ը ասում է, որ համակարգչի ժամացույցը դրված է վերջին գործարկումից առաջ, ուղղեք ամսաթիվը կամ թարմացրեք լիցենզիան առցանց։
