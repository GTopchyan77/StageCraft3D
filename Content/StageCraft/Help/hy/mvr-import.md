# MVR տեսարանի ներմուծում
keywords: mvr, ներմուծել mvr, լուսային պլան, պլան, ռիգ, ֆոկուսի կետ, շերտ, vectorworks, grandma3, capture, my virtual rig, import mvr, lighting plot, rig
panel: StageCraft.Panel.Library

MVR ֆայլը (.mvr) ամբողջական լուսային ռիգ է նախագծման կամ վահանակի ծրագրից՝ Vectorworks Spotlight, grandMA3, Capture կամ Depence։ Այն պարունակում է սարքերը՝ իրենց GDTF տեսակներով, DMX հասցեներով, ID-ներով և դիրքերով, ֆերմաները և ֆոկուսի կետերը։ StageCraft-ը կարդում է ֆայլը և կառուցում ռիգը ձեր բեմի վրա։

- Ներմուծում՝ File > Import MVR Scene... և ընտրեք .mvr ֆայլը, կամ քաշեք այն Explorer-ից տեսադաշտի վրա։
- Մինչ որևէ բան կփոխվի, տեսնում եք, թե ինչ կա ֆայլում՝ շերտերը, սարքերը, ֆերմաները, ֆոկուսի կետերը և սարքերի յուրաքանչյուր տեսակ։ Տեսակը կամ «նոր» է (ավելացվում է Գրադարանին), կամ «Գրադարանում է» (օգտագործվում է ձեր պատճենը), կամ «չի կարող օգտագործվել»։ Այն սարքերը, որոնց տեսակը կամ DMX ռեժիմը հնարավոր չէ օգտագործել, տեղադրվում են որպես Sketch պատուհանի ընդհանուր սարք և նշվում են նշումներում։ IMPORT կամ CANCEL։
- Սարքերը պահում են իրենց դիրքը, DMX հասցեն (ունիվերս և հասցե) և ID-ն, եթե այն ազատ է. զբաղված ID-ի դեպքում տրվում է հաջորդ ազատը։ Ֆոկուսի կետ ունեցող սարքը ուղղվում է դեպի այն (pan և tilt՝ իր հնարավորության սահմաններում)։
- Ֆերմաները դառնում են ամբողջական հատվածներից ֆերմայի գծեր՝ ֆայլի ֆերմայի երկարությամբ, Sketch պատուհանի ֆերմայով։ Ուղղահայաց աշտարակները, դեկորները, հենարանները և տեսաէկրանները նշվում են, բայց այս տարբերակում չեն տեղադրվում։
- Յուրաքանչյուր շերտ դառնում է սարքերի խումբ՝ շերտի անունով։
- Ամբողջ ներմուծումը մեկ հետարկման քայլ է (Ctrl+Z)։ Այն սարքերի տեսակները, որոնք ավելացվել են, մնում են Գրադարանում։
- Նույն ֆայլի կրկնակի ներմուծումը չի կրկնապատկում սարքերը. բեմում արդեն եղածները բաց են թողնվում։
- Մեծ ռիգերը տեղադրվում են յուրաքանչյուր կադրում մի մաս, որպեսզի StageCraft-ը շարունակի արձագանքել. վերանայման պատուհանը ցույց է տալիս ընթացքը։
