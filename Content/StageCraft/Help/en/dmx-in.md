# DMX IN: following an external console
keywords: dmx in, input, art-net, artnet, sacn, e1.31, external, console, visualiser, visualizer, receive, network
panel: StageCraft.Panel.Patch
control: DMXIn

DMX IN in the Patch panel receives Art-Net (port 6454) and sACN (port 5568) from a console or visualiser on the network and lets it drive the fixtures. The show switches to EXTERNAL DMX (Cues panel).

While External:
- cues cannot play, and STORE records the incoming look;
- effects hold, and DMX OUT pauses so the show does not echo the console back.

Switch the Cues panel back to INTERNAL to run your own cues. Windows may ask to allow StageCraft on the network the first time.
