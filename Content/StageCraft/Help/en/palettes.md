# Palettes
keywords: palette, palettes, preset, presets, colour palette, color palette, position palette, beam palette, record palette, per fixture, reference
panel: StageCraft.Panel.Palettes
control: RecordPalette

A palette is a named look for one feature (colour, position, beam, intensity or all). Click a palette to apply it to the selected fixtures.

- RECORD records what the selected fixtures show as a palette for any fixture: a colour palette keeps the primary fixture's colour, which every fixture mixes its own way.
- RECORD PER FIXTURE keeps each selected fixture's own values exactly (positions aimed one by one).

Cues stored with a palette refer to it: UPDATE the palette and every cue that uses it changes with it. Deleting a used palette keeps its values in those cues, so nothing on stage changes.
