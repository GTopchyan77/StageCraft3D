# Saving and opening scenes
keywords: save, saving, open, scene, scenes, file, autosave, recover, template, new stage, load

A scene is the whole stage: items, fixtures, patch, cues, playbacks, palettes, groups and effects. File › Save Scene As... saves it under a name (Ctrl+S saves again); File › Open Scene opens one, and asks first when the stage has unsaved changes.

File › New from Template starts from a starter stage. StageCraft also autosaves; File › Recover Autosave brings back the last autosave of a scene. The assistant never saves, opens or clears a stage for you.
